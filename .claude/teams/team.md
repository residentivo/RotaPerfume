# SistemaCompleto Team

## Estrutura do Time

| Membro | Função | Especialidade |
|--------|--------|---------------|
| MegaBrain | Líder | Coordenação geral |
| SubBrain | Analista | Análise e documentação |
| DataBrain | Database | Banco de dados |
| BackBrain | Backend | APIs em Go |
| FrontBrain | Frontend | Next.js + TypeScript |
| TestBrain | Tester | Testes automatizados |

## Fluxo de Trabalho

1. **Líder (MegaBrain)** recebe prompt do usuário
2. **Líder** separa features e envia para devs corretos
3. **Analista (SubBrain)** planeja tarefas por camada
4. **Database (DataBrain)** cria tabelas necessárias
5. **Backend (BackBrain)** desenvolve APIs em Go
6. **Frontend (FrontBrain)** implementa interfaces
7. **Tester (TestBrain)** valida com testes
8. **Analista** documenta e cria manuais
